# LUT Calibrations

To perform Colbert measurements, precise grayscale phase calibration is required. LUT (Look-Up Table) calibration can be performed from the "LUT Calibration" tab.

1. Opening the Colbert software imports the linear LUT file into the SLM hardware. LUT calibration must always be performed with the linear LUT file and varies slightly depending on the wavelength. Once the wavelength is selected and the configuration aligned, the user must ensure that the first-order diffraction (only the first order) of the SLM is measured. To do this, a diffraction grating with the appropriate period must be applied to the SLM.

2. Next, adjust the detector parameters to obtain sufficient intensity without saturation. This calibration can be performed in triggered or continuous mode.

3. In the "LUT Calibration" tab, define the laser's center wavelength and the previously selected grating period. You can then start the measurement by clicking on `Measure Spectrum`. The SLM will apply the stripe pattern, increasing the gray value (from 0 to 255 for 8 bits and from 0 to 1023 for 10 bits) at each iteration. The recorded intensity corresponds to the integral of the signal around the central wavelength.

4. The result is an oscillating curve with several maxima and minima, the number of which depends on the wavelength. The goal is to select the gray levels where the phase is equal to 0 and 2π. These two values ​​correspond to the first two minima. The second minimum is easy to define, but the first may not be a true minimum, but rather a point where the curve flattens out. For example, LUT calibration for 785 nm gives a value of approximately 100, and for 700 nm, the gray values ​​for the phases are 0 and 2π. Enter these values ​​in the two fields of the LUT Calibration tab.

5. The user can then click `Generate LUT File`. The program will first prompt them to save the calibration. The custom calibration is saved in the same folder as the original LUT files provided by the company. Next, the phase between the two gray levels will be calculated. The result should be a nonlinear curve where the phase is zero for the 0-phase gray level and equal to 1 (normalized by 2π) for the 2π-phase gray level. Between these two values, the intensity of 0.5 (0.5 × 2π = π) should correspond to a maximum of the oscillating curve. The program will then interpolate the phase based on the gray level and reconstruct the vector so that the phase is linear, but the corresponding gray level is nonlinear. In other words, the variable is inverted, transforming the phase into a linear vector instead of the applied linear gray level. The result is saved to a .lut file.

6. A `Clear graph` button next to the others clears the accumulated intensity curves, which is handy when repeating the measurement.

7. The final step is to verify the calibration. You can load the new LUT file by clicking the `Load LUT File` button and selecting the new custom calibration. Loading a LUT file into the SLM takes a few seconds; wait for the program to confirm the file loading after the message "Importing LUT File…" appears in the terminal window. Then repeat steps 3 through 5, but this time do not save (simply close the save window). The resulting phase curve should be linear, ranging from 0 to 1 (0 to 2π), while the intensity curve should have a less smooth shape than the previous sine-square curve. The path of the loaded LUT file is also stored in Data Handling, under `calibration['LUT_FilePath']`, so that saving the calibration records which LUT was in use and loading it reloads the same file into the SLM.
